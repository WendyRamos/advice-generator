# Advice Generator

Proyecto desarrollado como parte de un desafío de **Frontend Mentor**, enfocado en la creación de una interfaz responsive y en el consumo de una API para obtener y mostrar consejos de forma dinámica.

## ✨ Características

* Consumo de una API para obtener consejos aleatorios.
* Actualización dinámica del contenido mediante JavaScript.
* Diseño responsive adaptado a diferentes tamaños de pantalla.
* Interfaz basada en el diseño proporcionado por Frontend Mentor.
* Implementación de estados interactivos para el botón de generación de consejos.

## 🛠️ Tecnologías

* HTML5
* CSS3
* JavaScript
* Fetch API
* API REST

## 🎯 Objetivo

Practicar la manipulación del DOM, el consumo de APIs mediante `fetch()` y la creación de interfaces responsive a partir de un diseño de referencia.
